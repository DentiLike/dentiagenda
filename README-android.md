# DentiAgenda para Android

Rama aparte: aquí vive la app de Android (DentiAgenda + widget Mikes Molares).
No toca la app web (rama `main`).

Cada vez que cambia algo en `android/`, GitHub compila solo y deja el resultado en `apk/`:
- `apk/DentiAgenda.apk`: el instalador.
- `apk/estado.txt`: OK o FALLO.
